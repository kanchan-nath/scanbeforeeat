Authentication

Standard HTTP Header

All requests to the ScanBeforeEat Bio-Informatics Engine require an API Secret Token supplied in the HTTP Authorization header as a Bearer token. Live keys begin with sbe_live_ while Sandbox keys begin with sbe_test_.

Authorization: Bearer sbe_live_9a7d3f82e1c0b8924ff93a9082de71b4
POST

/v2/analyze/ingredients

Avg Latency: 24ms

Parses raw ingredient strings or unformatted OCR text, maps chemical synonyms to standard E-numbers, computes clinical toxicology penalties, and delivers NOVA-4 processing ratings with peer-reviewed citations.

tune Request Body (application/json)

Schema: IngredientAnalysisPayload
Parameter Type Requirement Description
ingredients_raw string Required Unformatted ingredient list or raw OCR string from packaging scan. Handled through multi-language bio-dictionary tokenizers.
barcode string Optional 8, 12, or 13-digit EAN/UPC identifier. When present, correlates packaging OCR with verified manufacturer nutritional data.
strict_mode boolean Optional Defaults to false. When true, enables pediatric allergen flags and EU banned thresholding (Southampton Six dyes, Titanium Dioxide).
include_alternatives boolean Optional Returns up to 3 lower-processed, clean pantry swap recommendations with NOVA 1 or 2 classifications.
Request Body 
curl -X POST https://api.scanbeforeeat.com/v2/analyze/ingredients \
  -H "Authorization: Bearer sbe_live_9a7d3f82e1c0b..." \
  -H "Content-Type: application/json" \
  -d '{
    "ingredients_raw": "Corn, Vegetable Oil, Maltodextrin, Salt, Monosodium Glutamate (E621), Sunset Yellow (E110), Artificial Flavor",
    "barcode": "028400042451",
    "strict_mode": true,
    "include_alternatives": true
  }'
