Core REST Endpoints

POST /v1/scan/upc
Barcode Scanning Endpoint

Request Body JSON

{
  "upc": "049000028904",
  "user_profile_id": "usr_998a7bc",
  "include_tox_score": true
}

Response Schema Preview

{
  "status": "success",
  "product": {
    "name": "Diet Sparkling Beverage",
    "safety_grade": "A",
    "allergens": [],
    "additives": [{"code": "E951", "risk_level": "low"}]
  }
}
GET /v1/additives/{id}
Additive Toxicology Endpoint

Parameters

id (string, required) - E-number or chemical identifier.

Code Snippet (cURL)

curl -X GET "https://api.scanbeforeeat.com/v1/additives/E250" \
     -H "Authorization: Bearer sbe_live_sec_1092"

SDK Quickstart

Python SDK pip install sbe-sdk 
from scanbeforeeat import Client
client = Client(api_key="sbe_live_...")
report = client.scan_upc("049000028904")
print(report.safety_grade)
Node.js SDK npm i @sbe/api 
import { SBEClient } from '@sbe/api';
const sbe = new SBEClient({ apiKey: 'sbe_live_...' });
const analysis = await sbe.scanBarcode('049000028904');
console.log(analysis.additives);
